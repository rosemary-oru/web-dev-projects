# Web Development Projects

A collection of beginner web development projects I built while learning **HTML, CSS, and JavaScript**. Each folder is a separate project, and together they show how my skills have grown, from basic page layouts to interactive games.

## Projects

| Project | Description |
| --- | --- |
| **dicee Game** | Two dice are rolled and the page announces the winner. |
| **Drum Kit** | Play drum sounds by clicking the buttons or pressing keys on the keyboard. |
| **Simon Game Challenge** | A memory game: repeat the growing pattern of colors and sounds to keep playing. |

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event listeners, functions, arrays)
- Git and GitHub

## What I Learned

- Structuring web pages with semantic HTML
- Styling and laying out pages with CSS
- Making pages interactive with JavaScript events
- Working with the DOM to update content dynamically
- Playing audio and handling keyboard input in the browser
- Using Git and GitHub to save and share my work

## How to Run a Project

1. Clone this repository:
   ```bash
   git clone https://github.com/rosemary-oru/web-dev-projects.git
   ```
2. Open the folder of the project you want to try.
3. Double-click its `index.html` file (or `dicee.html` for the Dicee game) to open it in your browser.

No installation is needed.
